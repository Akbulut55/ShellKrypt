# Contributing To ShellKrypt Legacy

ShellKrypt Legacy is archived and does not accept new issues, pull requests, or
other contributions. It is retained as a historical source snapshot under the
[`ShellKrypt Legacy Source License 1.0`](LICENSE).

The separately maintained [ShellKrypt](https://github.com/Akbulut55/ShellKrypt)
project has its own source tree, contribution policy, license, and technical
direction. A proposal for that project must follow the documents in that
repository; this legacy repository does not grant or imply contribution rights
there.

## Historical Contributions

Contributions submitted before archival remain governed by the contributor
terms accepted when they were submitted. Archiving the repository does not
revoke or replace previously granted rights.

## Security Reports

This archived code does not receive security fixes. Do not include real vaults,
credentials, backups, exports, or private logs in public reports. See
[`SECURITY.md`](SECURITY.md) for the legacy security status.
